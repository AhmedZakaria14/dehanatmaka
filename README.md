# dehanatmaka.com

موقع خدمات الدهانات والإيبوكسي في مكة المكرمة، منشور كملفات ثابتة على Vercel.

## التحقق المحلي

يتطلب Node.js 20 أو أحدث:

```bash
npm test
```

يفحص الاختبار عناوين الصفحات وأوصافها وروابط canonical والبيانات المنظمة والملفات المحلية وخريطة الموقع وصحة JavaScript.

## النشر

ينشر Vercel الفرع الرئيسي، مع تحويل الروابط إلى مسارات نظيفة حسب `vercel.json`. يجب تشغيل `npm test` قبل دمج أي تغيير.

تحتوي `assets/index-*.js` على حزمة التطبيق المبنية. عند توفر مشروع React الأصلي، ينبغي الاحتفاظ بمصدره وإعداد البناء وملف القفل في هذا الريبو بدلاً من تعديل الحزمة المبنية يدوياً.
